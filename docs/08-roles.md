# 08 · ยศ และสิทธิ์การมองเห็นระบบ

ใช้ล็อกระบบ (เช่น "ร้าน", "ถึงอนาคต") ให้เห็นเฉพาะคนที่มียศที่เลือก

| ใคร | เห็นอะไร |
|---|---|
| **แอดมิน** | ทุกระบบเสมอ + กล่อง `admin.exe` ในหน้าตั้งค่า (ตั้งยศ / ตั้งว่าใครเห็นระบบไหน) |
| **คนที่มียศ** | ระบบที่ "ทุกคนเห็น" + ระบบที่ล็อกไว้แต่ติ๊กยศของเขา (**ไม่เห็นชื่อยศตัวเอง**) |
| **คนทั่วไป (ไม่มียศ)** | เฉพาะระบบที่ "ทุกคนเห็น" |

- หน้าแรก / ตั้งค่า / ถังขยะ ทุกคนเห็นเสมอ (ล็อกไม่ได้)
- ค่าเริ่มต้น: **ถึงอนาคต** กับ **ร้าน** = เฉพาะยศ (ยังไม่ให้ยศใคร = แอดมินเห็นคนเดียว) ส่วนระบบอื่น = ทุกคน
- **ข้อมูลยังแยกกันเหมือนเดิม** : คนที่ได้ยศ "ร้าน" จะได้ร้านของตัวเอง (ว่างๆ) ไม่เห็นข้อมูลร้านของแอดมิน

---

## ตั้งค่าครั้งแรก
1. Supabase → SQL Editor → รัน `supabase/sql/004_roles.sql`
2. ตั้งตัวเองเป็นแอดมิน: รันคำสั่งนี้ (เปลี่ยนเป็นอีเมลที่ใช้ล็อกอินเว็บ)
   ```sql
   insert into public.app_admins (email) values (lower('you@example.com')) on conflict do nothing;
   ```
3. เปิดเว็บใหม่ → หน้าตั้งค่า จะมีกล่อง `admin.exe`

## ใช้งาน (ในกล่อง admin.exe)
1. **สร้างยศ** เช่น "ทีมร้าน"
2. **ใส่อีเมล** คนที่จะให้ยศนี้ (อีเมลที่เขาใช้สมัครเว็บ) ใส่ก่อนเขาสมัครก็ได้
3. ส่วน **ใครเห็นระบบไหน** : ระบบที่จะล็อก กด "เฉพาะยศ" แล้วติ๊กยศที่เห็นได้
4. อีกฝั่งจะเห็นผลเมื่อเปิดเว็บใหม่ หรือสลับแอพแล้วกลับมา

## ทำงานยังไง (สำหรับคนแก้โค้ด)

### ฐานข้อมูล (`004_roles.sql`)
| ตาราง / ฟังก์ชัน | ทำอะไร |
|---|---|
| `app_admins` | อีเมลแอดมิน |
| `roles` | ยศ |
| `role_members` | อีเมลไหนอยู่ยศไหน |
| `feature_rules` | ระบบไหนล็อก (`is_locked`) + ยศที่เห็นได้ (`allowed_role_ids`) / ไม่มีแถว = ทุกคนเห็น |
| `is_admin()` | ฉันเป็นแอดมินไหม |
| `can_use_feature('shop')` | ฉันใช้ระบบนี้ได้ไหม |
| `get_my_access()` | ส่งกลับแค่ "เป็นแอดมินไหม + id ระบบที่เห็นไม่ได้" (ไม่บอกชื่อยศ) |

- 4 ตารางบน **อ่าน/แก้ได้เฉพาะแอดมิน** คนอื่นเรียกแล้วได้ข้อมูลว่างเปล่า → จึงไม่รู้ยศตัวเอง
- **ล็อกถึงฐานข้อมูลจริง** ไม่ใช่แค่ซ่อนเมนู: กฎ "owner only" ของตาราง notes, tasks, future_messages, shop_* เช็ค `can_use_feature(...)` ด้วย
  ไม่มีสิทธิ์ = อ่าน/เขียนข้อมูลระบบนั้นไม่ได้ แม้จะยิงคำสั่งตรงๆ

| `src/features/settings/RoleManager.tsx` | หน้าตาตั้งค่ายศ (เฉพาะแอดมิน) |

### เพิ่มระบบใหม่ แล้วอยากให้ล็อกได้ถึงฐานข้อมูล
ระบบใหม่จะโผล่ในรายการ "ใครเห็นระบบไหน" เอง (ซ่อนเมนู + กันลิงก์ได้ทันที)
ถ้าอยากล็อกถึงข้อมูลด้วย ให้เขียนกฎของตารางใหม่แบบนี้ (`'diary'` = `id` ใน feature.tsx):
```sql
create policy "owner only" on public.diary
  for all using (user_id = auth.uid() and (select public.can_use_feature('diary')))
  with check (user_id = auth.uid() and (select public.can_use_feature('diary')));
```

### ข้อควรรู้
- ยังไม่ได้รัน `004_roles.sql` = ทุกคนเห็นทุกระบบ (เหมือนก่อนมีระบบยศ)
- เช็คสิทธิ์จาก **อีเมลที่ล็อกอิน** ถ้าเขาเปลี่ยนอีเมล ต้องใส่อีเมลใหม่ในยศ
- ลบยศ / เอาคนออกจากยศ ข้อมูลของเขาไม่หาย แค่เปิดระบบนั้นไม่ได้ ให้ยศคืนก็กลับมาเห็นเหมือนเดิม
