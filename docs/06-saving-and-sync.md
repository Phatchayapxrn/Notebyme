# 06 · การบันทึก และข้อมูลตรงกันทุกเครื่อง

## 💾 การบันทึกไอเดีย (`useAutoSave`)

ไฟล์: `src/shared/data/useAutoSave.ts` · ใช้ใน `src/features/notes/pages/NoteEditPage.tsx`

### บันทึกเมื่อไหร่บ้าง
| เหตุการณ์ | บันทึก? |
|---|---|
| หยุดพิมพ์ 0.8 วินาที | ✅ อัตโนมัติ |
| กดปุ่ม **บันทึก** หรือ **Ctrl+S / Cmd+S** | ✅ ทันที + เด้งข้อความ "บันทึกแล้ว" |
| กดย้อนกลับ / ไปหน้าอื่น | ✅ |
| สลับแอพ / ล็อกจอมือถือ | ✅ |
| ปิดแท็บ | ✅ (พยายามบันทึกก่อนปิด) |
| เน็ตกลับมา หลังจากหลุด | ✅ ส่งที่ค้างอยู่ |

### สถานะที่แสดง (`SaveStatusText`)
| สถานะ | ข้อความ |
|---|---|
| `saved` | ✓ บันทึกแล้ว |
| `not-saved` | ✏️ ยังไม่บันทึก |
| `saving` | กำลังบันทึก... |
| `failed` | บันทึกไม่สำเร็จ - กดบันทึกอีกครั้ง |
| `offline` | ไม่มีเน็ต - เก็บไว้ในเครื่องก่อน |

### ตอนเน็ตหลุด
1. บันทึกไม่สำเร็จ → เก็บ **ร่าง** ไว้ในเครื่อง (localStorage ชื่อ `draft:note-{id}`)
2. เน็ตกลับมา → ส่งให้อัตโนมัติ
3. ถ้าปิดเว็บไปก่อน → เปิดโน๊ตนั้นครั้งหน้า จะเช็คว่าร่างใหม่กว่าในฐานข้อมูลไหม ถ้าใหม่กว่าจะ **กู้ร่างกลับมาให้**

> ⚠️ ไฟล์รูป/วิดีโอต้องมีเน็ตถึงจะอัปโหลดได้

### ปรับเวลารอ
```ts
useAutoSave({ ..., waitTime: 800 })   // มิลลิวินาที (1000 = 1 วินาที)
```

### ใช้กับหน้าอื่น
```tsx
const { saveStatus, saveNow } = useAutoSave({
  value: { title, text },                 // ข้อมูลที่จะบันทึก (เปลี่ยนเมื่อไหร่ จะเริ่มนับเวลา)
  saveValue: (value) => saveDiary(id, value),
  isReady: !isLoading,                    // รอโหลดเสร็จก่อน (ไม่งั้นจะบันทึกค่าว่างทับ)
  draftName: `diary-${id}`,               // ชื่อร่าง (ไม่ใส่ = ไม่เก็บร่าง)
})
<SaveStatusText saveStatus={saveStatus} />
<RoundButton onClick={saveNow}>บันทึก</RoundButton>
```

### งาน (tasks) และหมวด
บันทึกทันทีทุกครั้งที่กด (ติ๊ก, เพิ่ม, แก้ข้อความแล้วกด Enter) ไม่ต้องรอ

## 🔄 ข้อมูลตรงกันทุกเครื่อง (`useLiveList`)

ไฟล์: `src/shared/data/useLiveList.ts`

```tsx
const { items, isLoading } = useLiveList({ tableName: 'notes', getList: getAllNotes })
```

`useLiveList` จะโหลดรายการใหม่เมื่อ
1. **เครื่องนี้** เพิ่ม/แก้/ลบ → ฟังก์ชันใน `database.ts` เรียก `tellListChanged('notes')`
2. **เครื่องอื่น** เพิ่ม/แก้/ลบ → Supabase Realtime ส่งสัญญาณมา (กรองเฉพาะข้อมูลของเรา `user_id=eq.{id}`)

ถ้าเปลี่ยนหลายครั้งติดๆ กัน จะรอ 0.15 วินาทีแล้วโหลดทีเดียว (ไม่โหลดซ้ำๆ)

> 💡 หน้าแก้ไขโน๊ต **ไม่** โหลดใหม่ระหว่างพิมพ์ (กันข้อความที่กำลังพิมพ์หาย)
> ถ้าแก้โน๊ตเดียวกันพร้อมกัน 2 เครื่อง อันที่บันทึกทีหลังจะทับอันแรก

### ถ้าอัปเดตสดไม่ทำงาน
- เช็คว่ารันส่วนท้ายของ `001_start.sql` แล้ว (`alter publication supabase_realtime ...`)
- ใน Supabase: **Database > Publications > supabase_realtime** ต้องมีตาราง groups / notes / tasks
- ถึงไม่มี realtime ก็ยังใช้ได้ปกติ แค่ต้องรีเฟรชถึงจะเห็นของจากเครื่องอื่น

## 🔐 ล็อกอิน
- `LoginProvider` (`src/shared/login/`) จำผู้ใช้ไว้ และ Supabase เก็บการล็อกอินในเครื่อง → ไม่ต้องล็อกอินใหม่ทุกครั้ง

- ฟังก์ชัน `logIn`, `signUp`, `logOut` อยู่ใน `src/features/login/loginActions.ts` (error แปลเป็นไทยแล้ว)
