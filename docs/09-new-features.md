# 09 · ระบบใหม่ (เมล / โน๊ตเร็ว / แชท / ปฏิทิน / ค้นหา / ออฟไลน์)

> เลขไฟล์ SQL ข้ามจาก 007 ไป 010 เพราะเคยทำระบบ "ไอเดียเว็บ" และ "บัญชี" แล้วเอาออก (เลขเดิมไม่เอามาใช้ซ้ำ)

ระบบใหม่ทั้งหมด **ล็อกให้เห็นเฉพาะแอดมินตั้งแต่เริ่ม** จนกว่าจะไปติ๊กยศให้ที่ หน้าตั้งค่า → ยศ

## วิธีเปิดใช้ (ครั้งเดียว)
รัน SQL ตามลำดับใน Supabase → SQL Editor (ไฟล์อยู่ `supabase/sql/`):

| ไฟล์ | ระบบ | id ที่ใช้ติ๊กยศ |
|---|---|---|
| 005_new_features_locked.sql | ล็อกทุกระบบด้านล่างให้เฉพาะแอดมิน | — |
| 006_mails.sql | เก็บเมล (เมล+รหัสแยกเป็นชุด) | `mails` |
| 007_plain_notes.sql | โน๊ตทั่วไป (โน๊ตเร็ว) | `plain_notes` |
| 010_chat.sql | แชทเก็บข้อความส่วนตัว | `chat` |
| 011_calendar.sql | ปฏิทิน | `calendar` |

## ออฟไลน์
- โค้ดอยู่ที่ `src/shared/offline/` — ระบบใหม่ทุกระบบอ่าน/เขียนผ่าน `listRows / insertRow / updateRow / deleteRow` (ไฟล์ `offlineData.ts`)
- ออฟไลน์: อ่านจากสำเนาในเครื่อง (IndexedDB) เขียนได้ เข้าคิวไว้ แล้วส่งขึ้น Supabase เองเมื่อเน็ตกลับมา
- แก้ชนกัน = คำสั่งที่ส่งทีหลังชนะ
- **ยังไม่ครอบคลุม:** ไอเดีย(notes) / งาน / ถึงอนาคต / ร้าน (ระบบเดิม ยังเรียก Supabase ตรง) และการแนบรูป/วิดีโอ (ต้องมีเน็ต)
- ตอนออกจากระบบ จะส่งคิวที่ค้างแล้วล้างสำเนาในเครื่อง
- ถ้าจะลองติดตั้งเป็นแอพ/ออฟไลน์จริงบนมือถือ ต้องเปิดผ่าน https (เช่นหลัง deploy Cloudflare)

## ค้นหากลาง
- เปิดด้วย Ctrl+K หรือ `/` หรือปุ่มแว่นขยาย (`src/shared/search/SearchBox.tsx`)
- ค้นเฉพาะระบบที่คนนั้นมีสิทธิ์เห็น ผ่าน `searchItems` ของแต่ละ feature (ไฟล์ `search.ts` ในแต่ละระบบ)
- ล่างสุดมี "ค้นหาบน Google" / "เปิดเว็บ" (ถ้าพิมพ์เป็นลิงก์)
- เมลค้นจาก "ชื่อชุด/ชื่อช่อง" เท่านั้น ไม่ค้นในค่าจริง (รหัสผ่านจะไม่โผล่ในผลค้นหา)
- ระบบใหม่ที่อยากให้ค้นได้ ให้เขียน `searchItems` แล้วใส่ใน `feature.tsx`

## ข้อควรรู้เรื่องเมล
เก็บรหัสเป็นข้อความธรรมดา (ไม่เข้ารหัส) ป้องกันด้วย RLS + ยศ ใครเข้า Supabase Dashboard ได้ก็เปิดอ่านตาราง `mail_sets` ได้

## ปฏิทิน
- มุมมอง เดือน / สัปดาห์ (รายการ 7 วัน) / วัน (ตารางเวลารายชั่วโมง)
- กิจกรรมซ้ำ รายวัน/สัปดาห์/เดือน/ปี เก็บแถวเดียว คำนวณวันที่ซ้ำฝั่งเว็บ (แก้/ลบ = ทั้งชุดที่ซ้ำ)
- กิจกรรมมีแค่วันเดียว (ยังไม่รองรับกิจกรรมข้ามหลายวัน)
- การเตือนทำงานเฉพาะตอนเปิดแอพอยู่ (ปิดแท็บแล้วไม่เตือน — ต้องมีเซิร์ฟเวอร์ส่ง push ซึ่งยังไม่ได้ทำ)
