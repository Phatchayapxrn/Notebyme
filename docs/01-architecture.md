# 01 · โครงสร้างโปรเจกต์

เอกสารนี้อธิบายว่าโปรเจกต์แบ่งเป็นส่วนไหนบ้าง แต่ละโฟลเดอร์/ไฟล์ทำอะไร และข้อมูลวิ่งไปทางไหน

---

## ภาพรวมแบบสั้นที่สุด

```
ผู้ใช้กดปุ่ม
   ↓
หน้าจอ (pages / parts)          ← src/features/*/pages, parts
   ↓ เรียกฟังก์ชัน
ฟังก์ชันอ่าน/เขียนข้อมูล          ← src/features/*/database.ts
   ↓ ใช้ตัวเชื่อมต่อ
Supabase (ฐานข้อมูลบนเน็ต)       ← src/shared/database.ts
   ↓ แจ้งกลับว่าข้อมูลเปลี่ยน
หน้าจอทุกเครื่องอัปเดตเอง         ← src/shared/data/useLiveList.ts
```

---

## แผนผังโฟลเดอร์

```
เว็บจดโน๊ต/
├─ README.md                  วิธีติดตั้ง / รัน / ขึ้นเว็บจริง
├─ docs/                      เอกสารอธิบาย (ที่คุณกำลังอ่าน)
├─ supabase/sql/              ไฟล์สร้างตารางในฐานข้อมูล (เอาไปรันใน Supabase)
├─ public/                    ไฟล์ที่ใช้ตรงๆ ไม่ผ่านการแปลง
│  ├─ icons/                  ไอคอนแอพ (หัวใจ)
│  └─ patterns/               ลายปกการ์ดหมวดหมู่ (.svg)
├─ scripts/makeAppIcons.mjs   สคริปต์สร้างไอคอน
├─ ideapic/                   รูปตัวอย่างดีไซน์ที่ใช้อ้างอิง
├─ index.html                 หน้า HTML หลัก (ใส่ฟอนต์ / ตั้งค่าแอพมือถือ)
├─ tailwind.config.ts         ชื่อสี ฟอนต์ เงา ที่ใช้ใน class
├─ vite.config.ts             ตั้งค่าตัวรันเว็บ + PWA (ติดตั้งลงมือถือ)
├─ .env                       ค่าเชื่อมต่อ Supabase (ต้องสร้างเอง ดู README)
└─ src/                       โค้ดทั้งหมด
   ├─ main.tsx                ไฟล์แรกที่ทำงาน
   ├─ App.tsx                 สร้างหน้าทั้งหมดจากรายชื่อระบบ
   ├─ index.css               สีทั้งเว็บ + สไตล์พื้นฐาน
   ├─ shared/                 ของที่ "ทุกระบบใช้ร่วมกัน"
   └─ features/               "ระบบ" ต่างๆ แยกโฟลเดอร์ละระบบ
```

## `src/shared/` : ของที่ทุกระบบใช้ร่วมกัน

| โฟลเดอร์ / ไฟล์ | ทำอะไร |
|---|---|
| `database.ts` | ตัวเชื่อมต่อ Supabase (`database`) + `tellListChanged()` บอกหน้าจอให้โหลดใหม่ + `stopIfError()` |
| `dateTools.ts` | แสดงวันที่ภาษาไทย นับวัน เช่น `showShortDate`, `showDueText` ("พรุ่งนี้", "อีก 3 วัน") |
| `login/` | `LoginProvider` จำว่าใครล็อกอิน, `useLogin()` ดูผู้ใช้, `MustLogin` บังคับล็อกอินก่อนเข้า |
| `data/useLiveList.ts` | ดึงรายการจากตาราง + อัปเดตสดเมื่อข้อมูลเปลี่ยน (จากเครื่องนี้หรือเครื่องอื่น) |
| `data/useAutoSave.ts` | บันทึกอัตโนมัติเมื่อหยุดพิมพ์ + `saveNow()` สำหรับปุ่มบันทึก + เก็บร่างตอนเน็ตหลุด |
| `files/fileStorage.ts` | อัปโหลด / เปิด / ลบ ไฟล์รูปและวิดีโอ |
| `files/useFileLink.ts` | แปลง path ไฟล์ เป็นลิงก์ที่เปิดดูได้ |
| `files/useUploadFile.ts` | อัปโหลดพร้อมบอกสถานะ "กำลังอัปโหลด" |
| `groups/` | ทุกอย่างเกี่ยวกับ **หมวดหมู่** (ใช้ร่วมกันทั้งไอเดียและงาน) |
| `parts/` | ชิ้นส่วนหน้าจอ เช่น ปุ่ม กล่อง แท็บ (ดู [02-design-system.md](02-design-system.md)) |
| `layout/` | โครงหน้า: เมนูซ้าย เมนูล่าง แถบขวา |
| `theme/` | โหมดสว่าง / มืด (`themeTools.ts`, `ThemeButton.tsx`) |
| `text/` | ตัวช่วยข้อความ: `copyText.ts` คัดลอก + จัดบรรทัด, `fancyLetters.ts` ฟอนต์พิเศษ, `insertText.ts` ใส่ข้อความตรงเคอร์เซอร์ |

### `src/shared/groups/` (หมวดหมู่)
| ไฟล์ | ทำอะไร |
|---|---|

| `GroupPicker.tsx` | แถวปุ่มเลือกหมวด |
| `GroupEditBox.tsx` | กล่องเด้ง สร้าง/แก้ไขหมวด |

### `src/shared/layout/` (โครงหน้า)
| ไฟล์ | ทำอะไร |
|---|---|
| `PageLayout.tsx` | โครงหน้าหลัก: จอคอม = เมนูซ้าย + เนื้อหา + แถบขวา / มือถือ = หัวเว็บ + เนื้อหา + เมนูล่าง |

| `useAllFeatures.ts` | ให้หน้าต่างๆ ดึงรายชื่อระบบทั้งหมดได้ |

## `src/features/` : ระบบต่างๆ

**1 โฟลเดอร์ = 1 ระบบ** แต่ละระบบมีไฟล์ `feature.tsx` บอกข้อมูลระบบ (ชื่อเมนู ไอคอน หน้าต่างๆ)
แล้วไปลงทะเบียนใน `allFeatures.ts` → เมนูและหน้าจะถูกสร้างให้เอง

| โฟลเดอร์ | ระบบ | ลิงก์ |
|---|---|---|
| `home/` | หน้าแรก (รวมการ์ดของทุกระบบ) | `/` |
| `notes/` | ไอเดีย / โน๊ต (มีรูป วิดีโอ) | `/notes`, `/notes/:noteId` |
| `tasks/` | สิ่งที่ต้องทำ | `/tasks` |
| `future/` | ข้อความถึงตัวเองในอนาคต (เลือกวันเปิดอ่าน ถึงวันแล้วขึ้นหน้าแรก) | `/future` |
| `shop/` | จัดการร้าน: ชุดข้อความคัดลอกได้ / สินค้า / ออเดอร์ | `/shop` |
| `trash/` | ถังขยะ (รวมของที่ลบจากทุกระบบ) | `/trash` |
| `settings/` | ตั้งค่า (หมวดหมู่ พื้นที่ไฟล์ สำรองข้อมูล) | `/settings` |
| `login/` | เข้าสู่ระบบ / สมัคร | `/login` |

ไฟล์ที่ใช้กับทุกระบบ
| ไฟล์ | ทำอะไร |
|---|---|
| `AppFeature.ts` | "แบบฟอร์ม" ที่ทุกระบบต้องกรอก (`AppFeature`, `TrashActions`, `TrashItem`) |
| `allFeatures.ts` | รายชื่อระบบทั้งหมด (**เพิ่มระบบใหม่ = เพิ่ม 1 บรรทัดที่นี่**) |

### ข้อมูลใน `AppFeature` (แบบฟอร์มของระบบ)
| ช่อง | ต้องใส่? | ความหมาย |
|---|---|---|
| `id` | ✅ | ชื่อเรียกในโค้ด ห้ามซ้ำ เช่น `'notes'` |
| `menuName` | ✅ | ชื่อในเมนู เช่น `'ไอเดีย'` |
| `menuIcon` | ✅ | ไอคอน (จาก lucide-react) |
| `mainPath` | ✅ | ลิงก์หน้าหลัก เช่น `'/notes'` |
| `menuOrder` | ✅ | ลำดับในเมนู เลขน้อยอยู่ก่อน |
| `pages` | ✅ | รายการหน้า `{ path, element }` |
| `showInMenu` | | `false` = ไม่โชว์ในเมนู |
| `isPublic` | | `true` = ไม่ต้องล็อกอิน ไม่มีเมนู (ใช้กับหน้าล็อกอิน) |
| `homeCard` | | การ์ดที่ไปโชว์ในหน้าแรก |
| `homeOrder` | | ลำดับการ์ดในหน้าแรก (เลขน้อยอยู่บน / ไม่ใส่ = ใช้ `menuOrder`) |
| `sideCard` | | กล่องที่ไปโชว์ในแถบขวา (จอคอม) |
| `trashActions` | | ถ้ามีของที่ลบลงถังขยะได้ ใส่วิธีจัดการ (ดึง / กู้คืน / ลบถาวร) |
| `getBackupData` | | ดึงข้อมูลทั้งหมด สำหรับปุ่มสำรองข้อมูล |

## ไฟล์ในแต่ละระบบ (รูปแบบเดียวกันทุกระบบ)

```
features/notes/
├─ feature.tsx     ข้อมูลระบบ (ลงทะเบียน)
├─ types.ts        หน้าตาข้อมูล
├─ database.ts     ฟังก์ชันอ่าน/เขียนข้อมูลของระบบนี้
├─ pages/          หน้าเต็มๆ (1 ไฟล์ = 1 หน้า)
├─ parts/          ชิ้นส่วนหน้าจอที่ใช้เฉพาะระบบนี้
└─ README.md       อธิบายระบบนี้
```

## ขั้นตอนตอนเปิดเว็บ (ทำงานตามลำดับ)

1. `index.html` โหลด `src/main.tsx`
2. `main.tsx` ครอบแอพด้วย `LoginProvider` (จำผู้ใช้) และ `PopupMessageProvider` (ข้อความเด้ง)
3. `App.tsx` อ่าน `allFeatures` แล้วสร้างหน้า
   - หน้าที่ `isPublic` → เข้าได้เลย
   - หน้าอื่น → ครอบด้วย `MustLogin` + `PageLayout`
4. ถ้าล็อกอินอยู่ `App.tsx` จะเรียก `deleteOldTrash()` ลบของในถังขยะที่เกิน 30 วัน
5. แต่ละหน้าใช้ `useLiveList` ดึงข้อมูล และฟังการเปลี่ยนแปลง

---

## ตัวอย่าง: กด "ติ๊กเสร็จ" ในหน้างาน เกิดอะไรขึ้น?

1. `TaskRow.tsx` → ผู้ใช้กดวงกลม → เรียก `markTaskDone(id, true)`
2. `tasks/database.ts` → `markTaskDone` อัปเดตตาราง `tasks` ใน Supabase
3. แล้วเรียก `tellListChanged('tasks')`
4. ทุกหน้าที่ใช้ `useLiveList({ tableName: 'tasks' })` ได้ยิน → โหลดรายการใหม่ → หน้าจอเปลี่ยน
5. เครื่องอื่นที่เปิดอยู่ ได้ยินผ่าน Supabase Realtime → โหลดใหม่เหมือนกัน

## import แบบ `@/`
ในโค้ดจะเห็น `import ... from '@/shared/database'`
`@/` แปลว่า "โฟลเดอร์ `src/`" (ตั้งค่าไว้ใน `vite.config.ts` และ `tsconfig.json`) จะได้ไม่ต้องเขียน `../../../`
