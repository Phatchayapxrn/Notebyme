# 🌸 Idea Notes : เว็บจดไอเดีย + สิ่งที่ต้องทำ

เว็บแอพสำหรับ
- **จดไอเดีย** แยกเป็นหมวดหมู่ ใส่ **รูปภาพ / วิดีโอ** ได้
- **จดสิ่งที่ต้องทำ** ตั้งความสำคัญ และวันกำหนดส่งได้
- **ดูภาพรวม** ทุกอย่างในหน้าแรก
- **ถังขยะ** ลบแล้วกู้คืนได้ภายใน 30 วัน (เกินนั้นลบเองอัตโนมัติ)
- **บันทึกอัตโนมัติ** และมีปุ่ม "บันทึก" ให้กดเอง
- **ใช้ได้ทุกเครื่อง** ข้อมูลตรงกันทั้งมือถือและคอม (ติดตั้งลงหน้าจอ iPhone ได้)

## 🚀 ติดตั้งครั้งแรก (ทำครั้งเดียว ประมาณ 15 นาที)

### ขั้นที่ 1: ติดตั้งโปรแกรมที่ต้องใช้
1. ติดตั้ง **Node.js** (เวอร์ชัน 20 ขึ้นไป) จาก https://nodejs.org
2. เปิด Terminal ในโฟลเดอร์โปรเจกต์ แล้วพิมพ์
   ```bash
   npm install
   ```

### ขั้นที่ 2: สร้างฐานข้อมูลบน Supabase (ฟรี)
1. ไปที่ https://supabase.com กด **Start your project** แล้วสมัคร/ล็อกอิน
2. กด **New project** ตั้งชื่อ (เช่น `idea-notes`) ตั้งรหัสผ่านฐานข้อมูล เลือก Region **Southeast Asia (Singapore)** แล้วกด Create
3. รอสักครู่จนสร้างเสร็จ

### ขั้นที่ 3: สร้างตาราง
1. ในหน้า Supabase เมนูซ้าย กด **SQL Editor** แล้วกด **New query**
2. เปิดไฟล์ `supabase/sql/001_start.sql` คัดลอกทั้งหมด วางลงไป แล้วกด **Run**
3. กด **New query** อีกครั้ง แล้วทำแบบเดียวกันกับไฟล์ `supabase/sql/002_files.sql`
4. ถ้าขึ้น `Success. No rows returned` แปลว่าเรียบร้อย

### ขั้นที่ 4: ตั้งค่าการล็อกอิน
1. เมนูซ้าย กด **Authentication** > **Sign In / Providers** > **Email**
2. ถ้าไม่อยากต้องยืนยันอีเมลตอนสมัคร ให้ **ปิด Confirm email** แล้วกด Save
   (ถ้าเปิดไว้ ต้องกดลิงก์ในอีเมลก่อน ถึงจะเข้าสู่ระบบได้)

### ขั้นที่ 5: เชื่อมเว็บกับ Supabase
1. ใน Supabase กด **Project Settings** (รูปเฟือง) > **API** (หรือ **Data API**)
2. คัดลอก **Project URL** และ **anon public** key
3. ในโฟลเดอร์โปรเจกต์ คัดลอกไฟล์ `.env.example` แล้วตั้งชื่อใหม่เป็น `.env`
4. เปิด `.env` แล้ววางค่าที่คัดลอกมา
   ```
   VITE_SUPABASE_URL=https://abcdefgh.supabase.co
   VITE_SUPABASE_ANON_KEY=eyJhbGciOi...
   ```
   > ⚠️ ห้ามเอาไฟล์ `.env` ขึ้น GitHub (ตั้งค่าใน `.gitignore` ไว้ให้แล้ว)
   > ส่วน anon key ใส่ในเว็บได้ปลอดภัย เพราะมีกฎ RLS ป้องกันไว้ ทุกคนเห็นแค่ข้อมูลตัวเอง

## ▶️ รันเว็บบนเครื่องตัวเอง

```bash
npm run dev
```
แล้วเปิด http://localhost:5173 ในเบราว์เซอร์

| คำสั่ง | ทำอะไร |
|---|---|
| `npm run dev` | รันเว็บตอนพัฒนา (แก้โค้ดแล้วหน้าเว็บเปลี่ยนทันที) |
| `npm run build` | ตรวจโค้ด + สร้างเว็บจริงไว้ในโฟลเดอร์ `dist/` |
| `npm run preview` | เปิดดูเว็บที่ build แล้ว |
| `npm run make-icons` | สร้างไอคอนแอพใหม่ (รูปหัวใจ) |

### เปิดบนมือถือ (ตอนพัฒนา)
มือถือกับคอมต้องต่อ Wi-Fi เดียวกัน แล้วรัน `npm run dev -- --host`
จะได้ลิงก์ `Network: http://192.168.x.x:5173` เอาไปเปิดในมือถือ

## 🌐 เอาขึ้นเว็บจริง (ฟรี)

### แบบ Vercel (แนะนำ)
1. เอาโค้ดขึ้น GitHub
2. ไปที่ https://vercel.com > **Add New Project** > เลือก repo นี้
3. ในหัวข้อ **Environment Variables** ใส่ `VITE_SUPABASE_URL` และ `VITE_SUPABASE_ANON_KEY` (ค่าเดียวกับใน `.env`)
4. กด **Deploy** (ไฟล์ `vercel.json` ตั้งค่าให้แล้ว)

### แบบ Netlify
เหมือนกัน: Build command `npm run build`, Publish directory `dist` และใส่ Environment Variables 2 ตัว
(ไฟล์ `netlify.toml` ตั้งค่าให้แล้ว)

### ติดตั้งลง iPhone
เปิดเว็บใน **Safari** > กดปุ่ม **แชร์** > **เพิ่มไปยังหน้าจอโฮม**
จะได้ไอคอนหัวใจ เปิดแล้วเต็มจอเหมือนแอพ

## 🆘 ปัญหาที่เจอบ่อย

| อาการ | วิธีแก้ |
|---|---|
| ขึ้นหน้า "ยังไม่ได้เชื่อมฐานข้อมูล" | ยังไม่ได้สร้างไฟล์ `.env` หรือใส่ค่าผิด แก้แล้ว **ปิด `npm run dev` แล้วเปิดใหม่** |
| `Invalid path specified in request URL` | `VITE_SUPABASE_URL` ใน `.env` ต้องจบที่ `.supabase.co` ห้ามมี `/rest/v1/` ต่อท้าย |
| สมัครแล้วเข้าไม่ได้ "ยังไม่ได้ยืนยันอีเมล" | เช็คอีเมลแล้วกดลิงก์ หรือปิด Confirm email (ขั้นที่ 4) |
| บันทึกไม่ได้ / error เกี่ยวกับ table | ยังไม่ได้รันไฟล์ SQL ในขั้นที่ 3 |
| อัปโหลดรูปไม่ได้ | ยังไม่ได้รัน `002_files.sql` |
| แก้ในมือถือแล้วคอมไม่อัปเดตทันที | ต้องรัน `001_start.sql` ให้ครบ (ส่วนท้ายเปิด Realtime) / หรือรีเฟรชหน้า |
| วิดีโออัปไม่ได้ | ไฟล์ต้องไม่เกิน 50MB (ข้อจำกัดของ Supabase แบบฟรี) |
