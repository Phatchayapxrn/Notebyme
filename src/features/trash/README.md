# ระบบ "ถังขยะ" (trash)

หน้า `/trash` รวมของที่ลบจาก **ทุกระบบ** กู้คืน / ลบถาวร / ล้างถังขยะ ได้

| ไฟล์ | ทำอะไร |
|---|---|
| `feature.tsx` | ข้อมูลระบบ: เมนู "ถังขยะ" ลำดับ 90 |
| `TrashPage.tsx` | หน้าถังขยะ: แท็บแยกตามประเภท, จำนวนวันที่เหลือ, ปุ่มกู้คืน/ลบถาวร, ถามยืนยันก่อนลบ |
| `deleteOldTrash.ts` | `TRASH_KEEP_DAYS` (30 วัน), `daysLeftInTrash()`, `deleteOldTrash()` ลบของที่เกินกำหนด |

## ทำงานยังไง
- ถังขยะ **ไม่ได้** ดึงข้อมูลจากตารางเอง แต่ใช้ `trashActions` ที่แต่ละระบบใส่มาใน `feature.tsx`
  (`getTrashItems`, `bringBackFromTrash`, `deleteForever`)
- `deleteOldTrash()` ถูกเรียก 1 ครั้งทุกครั้งที่เปิดแอพ (ใน `src/App.tsx`)
- เหลือ ≤ 3 วัน ตัวเลขจะเป็นสีแดง

## อยากแก้...
| อยาก | แก้ที่ |
|---|---|
| เก็บนานกว่า/สั้นกว่า 30 วัน | `TRASH_KEEP_DAYS` ใน `deleteOldTrash.ts` (ข้อความในหน้าจะเปลี่ยนตาม) |
| ให้ระบบใหม่มีถังขยะ | ใส่ `trashActions` ใน `feature.tsx` ของระบบนั้น (ดู docs/04) |
