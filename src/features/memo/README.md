# ระบบ "โน๊ต" (memo) — โน๊ตแบบไอโฟน

โฟลเดอร์ + ปักหมุด + จัดกลุ่มตามเวลา + จัดรูปแบบข้อความ (ตัวหนา/เอียง/เส้นใต้/ขีดฆ่า/ไฮไลต์/ลิงก์/หัวเรื่อง/รายการ/เช็กลิสต์/ตาราง/แนบรูป-วิดีโอ)
แยกจาก "ไอเดีย" (notes) และ "โน๊ตเร็ว" (plain_notes) ไม่ยุ่งกัน

## ไฟล์ในระบบ

| ไฟล์ | หน้าที่ |
|---|---|
| `feature.tsx` | ลงทะเบียนระบบ (เมนู, หน้า, ค้นหา, ถังขยะ, สำรองข้อมูล) |
| `types.ts` | หน้าตาข้อมูล `Memo`, `MemoFolder` + `getMemoTitle` (ชื่อ = บรรทัดแรก) |
| `database.ts` | อ่าน/เขียนตาราง `memos` และ `memo_folders` (ผ่านชั้นออฟไลน์ ใช้ได้ตอนไม่มีเน็ต) |
| `groupByTime.ts` | จัดกลุ่ม วันนี้ / 7 วัน / 30 วัน / รายเดือน |
| `search.ts` | ให้ช่องค้นหากลางค้นในโน๊ตได้ |
| `pages/MemoListPage.tsx` | หน้ารายการ (`/memo`) มีแถบโฟลเดอร์ ค้นหา ปักหมุด |
| `pages/MemoEditPage.tsx` | หน้าเขียน (`/memo/:id`) บันทึกอัตโนมัติ ย้ายโฟลเดอร์ ปักหมุด ถังขยะ |
| `parts/MemoEditor.tsx` | ช่องเขียน (TipTap) |
| `parts/MemoToolbar.tsx` | แถบเครื่องมือลอยเหนือคีย์บอร์ด (โหมดหลัก / Aa / ลิงก์ / จัดการตาราง) |
| `parts/MemoRow.tsx` | แถวโน๊ตในรายการ |
| `parts/FolderEditBox.tsx` | สร้าง/แก้/ลบโฟลเดอร์ |

ฐานข้อมูล: `supabase/sql/012_memo.sql` (ต้องรันใน Supabase ก่อนใช้)
สไตล์เนื้อหา (ไฮไลต์ ตาราง ชื่อโน๊ตตัวใหญ่): ท้ายส่วน `.note-content` ใน `src/index.css`

## อยากแก้อะไร ไปที่ไหน

| อยากแก้ | ไปที่ |
|---|---|
| ปุ่มในแถบเครื่องมือ | `parts/MemoToolbar.tsx` |
| ช่วงเวลาที่จัดกลุ่ม (7 วัน / 30 วัน) | `groupByTime.ts` |
| ขนาดตารางตอนแทรก (3 แถว 2 คอลัมน์) | `insertTable({ rows, cols })` ใน `MemoToolbar.tsx` |
| อีโมจิให้เลือกตอนสร้างโฟลเดอร์ | `SUGGESTED_EMOJIS` ใน `shared/groups/groupTypes.ts` |
| ตำแหน่งในเมนู | `menuOrder` ใน `feature.tsx` |
| ให้คนอื่นเห็นระบบนี้ | ล็อกไว้ตั้งแต่เริ่ม (`012_memo.sql`) → แอดมินติ๊กยศที่ หน้าตั้งค่า → ยศ |

## ข้อควรรู้
- ลิงก์ในโน๊ต: กด Ctrl (หรือ ⌘) ค้างแล้วคลิกเพื่อเปิด
- แนบได้เฉพาะรูปและวิดีโอ (ใช้ระบบไฟล์ของแอพ) และต้องออนไลน์ตอนอัปโหลด
- ลบโฟลเดอร์ → โน๊ตข้างในไม่หาย จะไปอยู่ "ทั้งหมด" แบบไม่จัดหมวด
