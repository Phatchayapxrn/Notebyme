# ระบบ "ตั้งค่า" (settings)

หน้า `/settings`

| ไฟล์ | ทำอะไร |
|---|---|
| `feature.tsx` | ข้อมูลระบบ: เมนู "ตั้งค่า" ลำดับ 99 (อยู่ท้ายสุด) |
| `SettingsPage.tsx` | กล่อง: บัญชี (ออกจากระบบ), โหมดสี, ยศ (เฉพาะแอดมิน), หมวดหมู่, พื้นที่ไฟล์, สำรองข้อมูล, วิธีติดตั้งลงมือถือ |
| `RoleManager.tsx` | (เฉพาะแอดมิน) สร้าง/ลบยศ, ใส่อีเมลในยศ, ตั้งว่าระบบไหน "ทุกคน" หรือ "เฉพาะยศ" — ดู `docs/08-roles.md` |
| `GroupManager.tsx` | รายการหมวด: แก้ไข, เลื่อนขึ้น/ลง, ลบ (ถามยืนยัน), สร้างหมวดใหม่ |

## สำรองข้อมูล
ปุ่ม "ดาวน์โหลดไฟล์สำรอง" รวม `groups` + `getBackupData()` ของทุกระบบ เป็นไฟล์ `idea-notes-backup-YYYY-MM-DD.json`
(ไม่รวมตัวไฟล์รูป/วิดีโอ) ระบบใหม่ที่ใส่ `getBackupData` จะถูกรวมไปด้วยเอง

## เพิ่มกล่องตั้งค่าใหม่
คัดลอก `<WindowBox title="...exe">...</WindowBox>` ใน `SettingsPage.tsx` แล้วใส่เนื้อหาใหม่
