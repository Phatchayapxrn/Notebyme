# ระบบ "หน้าแรก" (home)

หน้า `/` แสดง **วันที่ + คำทักทาย** และ **การ์ดของทุกระบบ** (`homeCard`) เรียงตาม `menuOrder`

| ไฟล์ | ทำอะไร |
|---|---|
| `feature.tsx` | ข้อมูลระบบ: เมนู "หน้าแรก" ลำดับที่ 1 |
| `HomePage.tsx` | หน้าแรก + `getGreeting()` คำทักทายตามเวลา |

- หน้านี้ **ไม่รู้จัก** ระบบไหนเป็นพิเศษ แค่วนแสดง `homeCard` ของทุกระบบ
  → ระบบใหม่ที่ใส่ `homeCard` จะมาโผล่เอง ไม่ต้องแก้ไฟล์นี้
- ตอนนี้มี: การ์ดหมวดหมู่ + ไอเดียล่าสุด (จาก notes) และสรุปงาน (จาก tasks ซ่อนบนจอกว้างเพราะมีในแถบขวาแล้ว)
- แก้คำทักทาย: `getGreeting()` ใน `HomePage.tsx`
